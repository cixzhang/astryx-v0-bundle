# Astryx for v0

A public [v0 Design Systems 2.0](https://v0.app/docs/design-systems-2) bundle for [Astryx](https://github.com/facebook/astryx).

The bundle is pinned to Astryx `0.6.3` and intentionally consumes the public `@astryxdesign/*` packages instead of forking component implementations. It will include a verified v0 starter, all public Astryx page and block templates, all public themes, custom-theme examples, and generated validation metadata.

Implementation is in progress. The locked scope and source provenance are in [`docs/ledger.md`](docs/ledger.md).
